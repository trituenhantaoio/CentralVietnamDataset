# CentralVietnamDataset

Bộ dữ liệu về phương ngữ tiếng miền Trung Việt Nam, gồm các từ, cụm từ và câu cùng cách diễn đạt tương ứng bằng tiếng Việt phổ thông.

## Dataset

- `sentences.csv`: 1.246 cặp dữ liệu.
- `words.csv`: 294 cặp dữ liệu.

Mỗi file CSV gồm 2 cột, không có header:
- Cột 1: Phương ngữ miền Trung.
- Cột 2: Cách diễn đạt tương ứng.

## Call for Contributions

Chúng tôi hoan nghênh mọi đóng góp nhằm mở rộng và cải thiện bộ dữ liệu.

Bạn có thể đóng góp bằng cách:
- Bổ sung từ, cụm từ và câu mới.
- Sửa lỗi hoặc cải thiện dữ liệu hiện có.
- Tạo Issue hoặc Pull Request trên GitHub.
